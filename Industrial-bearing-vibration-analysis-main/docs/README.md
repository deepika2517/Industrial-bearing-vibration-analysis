# Documentation

Project report, methodology, and supporting documentation.

## Contents

- `methodology.md` — signal-processing pipeline and feature definitions.
- `report.md` — project report (populate with your findings).

## Methodology summary

```
raw signal
   │
   ├─ remove DC / detrend          (src.preprocessing)
   ├─ band-pass filter             (src.preprocessing)
   ├─ normalise (z-score)          (src.preprocessing)
   │
   ├─ time-domain features         (src.statistical_analysis)
   │     RMS, kurtosis, skewness, crest factor, ...
   │
   ├─ frequency-domain features    (src.fft_analysis)
   │     dominant frequencies, spectral centroid, band energy ratios
   │
   └─ condition comparison         (src.comparison)
         tables + figures in results/
```

## Feature reference

| Feature            | Domain    | Fault sensitivity                       |
| ------------------ | --------- | --------------------------------------- |
| RMS                | time      | overall energy increase                 |
| Kurtosis           | time      | impulsive faults (early detection)      |
| Crest factor       | time      | impulsive spikes                        |
| Skewness           | time      | asymmetric impacts                      |
| Spectral centroid  | frequency | shift of energy toward higher bands     |
| Band energy ratio  | frequency | localised defect-frequency energy       |

Add figures generated by `main.py` from `results/` and place the written report
alongside this file.
