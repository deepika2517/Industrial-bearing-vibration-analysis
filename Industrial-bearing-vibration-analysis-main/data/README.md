# Data

This folder holds dataset instructions and small sample recordings.

## Directory layout

```
data/
├── raw/            # (git-ignored) full recordings downloaded by you
│   ├── healthy/
│   ├── outer_race/
│   ├── inner_race/
│   └── ball/
├── samples/        # small committed examples for quick testing
│   ├── healthy_sample.csv
│   ├── outer_race_sample.csv
│   ├── inner_race_sample.csv
│   └── ball_sample.csv
└── README.md
```

Each recording is a one-column CSV (`amplitude`) or a MATLAB `.mat` file
containing a single numeric array. The **immediate parent folder name** is used
as the condition label when loading a directory.

## Expected format

| Column / array | Description              |
| -------------- | ------------------------ |
| `amplitude`    | vibration amplitude (g)  |

The sampling frequency is passed on the command line (`--fs`, default 12000 Hz).

## Getting the CWRU dataset

1. Visit the [CWRU Bearing Data Center](https://engineering.case.edu/bearingdatacenter).
2. Download the normal and fault `.mat` files you need.
3. Convert/rename them into the `data/raw/<condition>/` layout above, or load
   them directly with `src.data_loading.load_mat`.

## Sample data

The files in `data/samples/` are **synthetic** signals generated by
`src.data_loading.generate_synthetic_signal`. They are small enough to commit
and let the pipeline and dashboard run without downloading anything.

Regenerate them with:

```python
from src.data_loading import generate_synthetic_signal
import numpy as np
for condition in ["healthy", "outer_race", "inner_race", "ball"]:
    sig = generate_synthetic_signal(condition, fs=12000, duration=0.5)
    np.savetxt(f"data/samples/{condition}_sample.csv", sig,
               delimiter=",", header="amplitude", comments="")
```
